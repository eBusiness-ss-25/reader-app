# Basic Instructions

- Always write your code in English
- Document every change or addition you make

## Setup

1. Run `npm install` to install all dependencies.
2. Copy `.env.example` to `.env` or execute `agents/scripts/setup.sh`.
3. Start the development server with `npm run dev`.

## Useful Commands

- `npm run build` – build the Next.js app for production
- `npm start` – start the production server after building
- `npm run lint` – run ESLint against the codebase

The project requires Node.js version 18 or newer. No automated tests are included.
